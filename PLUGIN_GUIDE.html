HTTP Control

Universal Devices IoX / PG3x Node Server — Version 1.4.0

Overview

HTTP Control allows IoX programs and devices to communicate with HTTP-enabled equipment and web services.

Configure up to 16 independent endpoints, send HTTP requests, and expose numeric response values as IoX node drivers.

Features

  • GET, POST, PUT, and DELETE requests
  • Custom HTTP headers and JSON request bodies
  • Eight numeric response fields per endpoint
  • Nested JSON and array parsing
  • Plain-text numeric responses
  • Optional automatic polling for GET requests
  • HTTP status, response time, and success reporting
  • Previous measurements preserved after failed requests

Configuration

Open the plugin's Custom Parameters page in PG3x.

ParameterDescription
url1_nameIoX node name
url1_urlHTTP or HTTPS endpoint
url1_methodGET, POST, PUT, DELETE
url1_headersOptional JSON object containing headers
url1_bodyOptional request body
url1_intervalPolling interval in seconds; 0 disables
url1_field1 – url1_field8 Response values to extract

Repeat with url2_ through url16_ for additional endpoints.

Both name and URL are required. Save configuration changes and restart the plugin to apply them.

Example: JSON Response

url1_name = Temperature Monitor
url1_url = https://httpbin.org/anything?temperature=35&humidity=62
url1_method = GET
url1_field1 = args.temperature
url1_field2 = args.humidity
url1_interval = 60

Field 1 displays 35 and Field 2 displays 62.

Nested objects use dot notation. Array indices are numeric, for example sensors.0.temperature.

Example: Plain-Text Response

url1_url = https://httpbin.org/base64/NzIuNQ==
url1_method = GET
url1_field1 = text

Field 1 displays 72.5.

Plain-text responses must contain a numeric value.

Example: POST Request

url1_url = https://httpbin.org/anything
url1_method = POST
url1_body = {"temperature":47,"humidity":81}
url1_field1 = json.temperature
url1_field2 = json.humidity

Use the IoX Send Request command to execute the POST request.

Automatic Polling

Set urlN_interval to a positive number of seconds to enable automatic polling.

url1_interval = 60

Polling is checked during PG3x Short Poll events, so actual request frequency depends on the configured Short Poll interval.

Safety: Only GET requests are automatically polled. POST, PUT, and DELETE requests require explicit commands.

IoX Commands and Status

CommandFunction
Send RequestExecutes the configured HTTP request
QueryReports stored values without sending a request
StatusDescription
Last Request SuccessfulTrue for HTTP 200–299
HTTP Status CodeHTTP response code
Response Time (ms)Request duration
Fields 1–8Extracted numeric response values

Invalid or missing response fields retain their previous values. HTTP errors do not overwrite previous measurements.

Security and Limitations

  • Use HTTPS when available.
  • Store API credentials in PG3x configuration, not source code.
  • Protect access to PG3x configuration and diagnostic data.
  • HTTP requests time out after five seconds.
  • Redirects are not followed automatically.
  • Response fields currently support numeric values only.
